# 🚀 PixelForge – Digital Agency Website

PixelForge is a modern and responsive digital agency website built using React and Tailwind CSS. It showcases digital services, creative projects, team members, and contact information through a clean, interactive, and professional user interface.

The project focuses on modern UI design, responsive layouts, smooth navigation, reusable React components, and an interactive user experience.

---

## ✨ Features

- 🎨 **Modern UI Design** – Clean, professional, and visually appealing interface.
- 📱 **Fully Responsive** – Optimized for desktop, tablet, and mobile devices.
- 🌙 **Dark & Light Mode** – Switch between dark and light themes.
- 🏠 **Home Section** – Attractive hero section with introduction and trusted companies.
- 💼 **Services Section** – Showcases digital services offered by the agency.
- 🖥️ **Our Work Section** – Displays projects with images, descriptions, and technologies.
- 👥 **Our Team Section** – Introduces team members with profiles and roles.
- 📩 **Contact Section** – Contact form for user inquiries.
- 🔔 **Toast Notifications** – Interactive feedback using React Hot Toast.
- 🧭 **Navigation** – Smooth navigation between different pages using React Router.
- 🔗 **Footer Section** – Includes navigation links, social media links, and newsletter subscription UI.
- ⚡ **Reusable Components** – Organized component-based architecture.
- 🎯 **Interactive Elements** – Buttons, icons, forms, and theme switching.

## ⚙️ Installation & Setup

Follow these steps to run PixelForge locally.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to Project Directory

```bash
cd PixelForge
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```

## 🌙 Dark & Light Mode

PixelForge includes a theme switching feature that allows users to switch between dark and light modes.

- Dark Mode: Dark backgrounds with light text.
- Light Mode: Light backgrounds with dark text.
- Theme state is managed using React Context API.
- Theme changes are reflected across multiple components.
